ENKELT OCH TYDLIGT

Vi kombinerar teknisk kompetens med personlig service så att du förstår både lösningen och nästa steg.

Tydlig felsökning

Vi börjar med att förstå problemet innan vi gör förändringar. Du får en tydlig bild av vad som behöver göras och varför.

Personlig support

Rätt supportform

RUT-AVDRAG

Lägre arbetskostnad
för godkänd hjälp hemma.

Vissa IT-tjänster som utförs i hemmet kan omfattas av RUT-avdrag. Vi hjälper dig att förstå vad som gäller för just ditt uppdrag.

VANLIGA FRÅGOR

Bra att veta
innan du bokar.

Här hittar du svar på några av de vanligaste frågorna om priser och support.

Kontakta oss
Finns det några extra kostnader?+

Du får tydlig information om upplägg och pris innan arbetet börjar. Om förutsättningarna förändras berättar vi det innan vi går vidare.

Tillkommer rese- eller startkostnad?+

Det beror på vilken supportform och vilket uppdrag det gäller. Vi går igenom kostnaden med dig innan bokningen bekräftas.

Kan jag använda RUT-avdrag?+

För vissa IT-tjänster som utförs i hemmet kan RUT-avdrag vara möjligt. Vi hjälper dig att förstå vad som kan omfattas.

Kan företag boka support?+

Ja. Vi hjälper företag med bland annat datorer, Microsoft 365, nätverk, säkerhet och löpande IT-support.
